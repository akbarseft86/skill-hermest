## 0. Prinsip Inti — 3 Pertarungan

Setiap konten 300K+ views menang berurutan:

1. **Stop the Scroll** (1–3s) → Hook
2. **Build Belief** (3–25s) → Body: masalah nyata + solusi pas + untuk orang seperti aku
3. **Reduce Friction** (akhir) → CTA jelas, ringan

TikTok 2026: retensi >65% di detik ke-3 → algoritma push 4–7× lebih banyak impresi. Metrik utama: watch time, completion rate, rewatch rate. Bukan likes.

## 1. 4 Tipe Konten Pemenang

| Tipe | Tujuan | Karakter | Struktur Inti |
|------|--------|----------|---------------|
| **A. Performance Ad** | Konversi langsung | Direct, hard offer | Hook → Problem → Mechanism → Proof → Offer → CTA |
| **B. UGC / Spark Ad** | Konversi soft + trust | Native, ngomong seperti teman | Hook → My story → Demo → Reaction → CTA |
| **C. Organic Expert** | Authority + follower | Edukatif | Diagnosis → Reframe → Framework → Example → Save CTA |
| **D. Viral Storytelling** | Reach + retensi | Personal, dramatis | Hook → Scene → Tension → Turning → Mechanism → Lesson |

Mapping ke CAVAC:
- Tipe A & B = Concrete Value + Product POV (entry market)
- Tipe C = Bisa shift ke Audience POV setelah authority terbangun
- Tipe D = Pancingan top-of-funnel, value pelan-pelan

## 2. Hook Bank — 12 Pola Pemenang

Tiap pola: formula + contoh + trigger psikologi. Cocok di-combine 2–3 trigger sekaligus (pattern interrupt + curiosity gap + social proof = paling efektif).

### 1. Mistake Hook
- Formula: `[Kesalahan spesifik] yang bikin [hasil buruk], padahal kamu kira [asumsi umum]`
- Trigger: Takut salah
- Contoh: "Kebanyakan diet gagal bukan karena makanan, tapi karena ini." / "4 kesalahan pemula yang bikin video TikTok kamu nggak FYP."

### 2. Confession Hook
- Formula: `Aku baru sadar [fakta pahit] setelah [kejadian]`
- Trigger: Otentisitas → guard turun
- Contoh: "Aku resign dari kerjaan 12 juta sebulan, dan nggak nyesel." / "Aku habis 50 juta untuk kursus online, dan ini hasilnya."

### 3. Forbidden Knowledge Hook
- Formula: `Hal yang jarang dikasih tahu soal [topik]`
- Trigger: Akses eksklusif
- Contoh: "Trik jualan TikTok Shop yang dipakai seller top tapi jarang dibahas."

### 4. Enemy Hook
- Formula: `Masalahmu bukan [musuh palsu], tapi [musuh asli]`
- Trigger: Kambing hitam baru → merasa dimengerti
- Contoh: "Bukan kamu malas olahraga, tapi tubuhmu nggak punya sistem." / "Bukan anaknya susah makan, tapi tekstur MPASI-nya yang salah."

### 5. Tiny Detail Hook
- Formula: `Detail kecil ini bikin [hasil besar]`
- Trigger: Otak suka leverage kecil → hasil besar
- Contoh: "1 trik simple yang bikin engagement Instagram naik 300%."

### 6. Before-After Identity Hook
- Formula: `Dulu aku [identitas lama], sekarang [identitas baru] karena [mekanisme]`
- Trigger: Harapan transformasi
- Contoh: "Saldo rekeningku 3 bulan lalu vs sekarang. Mau tahu caranya?"

### 7. Pattern Interrupt Hook
- Formula: Kalimat yang bertentangan dengan common sense
- Trigger: Konflik kognitif → otak berhenti
- Contoh: "Saving money itu strategi paling buruk di tahun 2026." / "Stop pakai parfum mahal kalau kamu nggak ngerti basenote."

### 8. Social Proof Hook (Angka)
- Formula: `[Angka spesifik] terjadi setelah [aksi spesifik]`
- Trigger: Validasi cepat (angka spesifik > angka bulat: 3, 7, 21 > 5, 10, 100)
- Contoh: "Cara aku dapet 1000 followers TikTok dalam 14 hari." / "Aku udah coba 12 brand serum, dan cuma 1 yang beneran ngaruh."

### 9. POV / Relatable Scene Hook
- Formula: `POV: [situasi spesifik yang relate]`
- Trigger: "Ini gue banget" → empati
- Contoh: "POV: kamu baru sadar mantanmu sebenarnya red flag." / "POV: anak rantau yang baru sadar gaji UMR Jakarta nggak cukup."

### 10. Diagnosis Hook
- Formula: `Kalau [gejala], kemungkinan [diagnosa mengejutkan]`
- Trigger: Suka didiagnosa, dilabel
- Contoh: "Kalau iklanmu banyak ATC tapi nggak checkout, masalahnya bukan harga."

### 11. Warning / Reverse Hook
- Formula: `Jangan/Stop [aksi] kalau [kondisi]`
- Trigger: Loss aversion (takut rugi > mau dapat)
- Contoh: "Stop! Jangan beli iPhone 17 sebelum nonton video ini." / "Sebelum kamu KPR rumah, wajib tahu 3 hal ini."

### 12. Story Cliffhanger Hook
- Formula: `Aku hampir [gagal], sampai akhirnya [penemuan]`
- Trigger: Drama + janji solusi
- Contoh: "Cerita gue ditipu Rp 30 juta sama temen sendiri." / "Aku hampir tutup toko karena iklan boncos, sampai nemu pola ini."

## 3. Script Skeleton — 4 Pattern Siap Shoot

### PATTERN A — PERFORMANCE AD (15–30 detik)

```
[0-3s]   HOOK         Pattern interrupt / Mistake / Diagnosis
[3-7s]   PROBLEM      Spesifik. Pakai bahasa customer.
[7-12s]  MECHANISM    Kenapa produk bekerja (concrete value)
[12-20s] PROOF        Demo / before-after / angka / testi
[20-25s] OFFER        Harga, bundling, garansi, scarcity
[25-30s] CTA          "Klik link", "Order via keranjang kuning"
```

Contoh template (skincare jerawat — selaras CAVAC Product POV):
```
"Skincare mahal yang kamu pakai mungkin bikin jerawatmu makin parah."
"75% orang dengan kulit berminyak salah pilih moisturizer."
"Produk ini punya Salicylic Acid 2% + Centella — meredakan dalam 6 jam."
"Lihat sendiri: ini hari 1, ini hari 3."
"Hari ini 50% off, stok limited 200 pcs."
"Tap keranjang kuning sekarang."
```

### PATTERN B — UGC / SPARK AD (15–20 detik)

Direct Response 6-step (Motion):
`Hook → Problem → Solution → Value Prop → Social Proof → CTA`

```
[0-3s]   HOOK         Auditory: "Stop scrolling kalau kamu..."
                      Visual: Before-after instan
                      Word: "POV: kamu akhirnya nemu..."
[3-7s]   PROBLEM ID   "Kalau kamu kayak aku dan udah coba semua..."
[7-11s]  SOLUTION     "Lucky banget nemu [produk]..."
[11-15s] VALUE PROP   2-3 differensiator konkret
[15-18s] SOCIAL PROOF "Temenku [authority] juga pakai" / review overlay
[18-20s] CTA          Soft: "Cek link / keranjang"
```

### PATTERN C — ORGANIC EXPERT (30–60 detik)

```
[0-3s]   DIAGNOSIS    "Kalau kamu [gejala], kemungkinan [penyebab]..."
[3-8s]   REFRAME      "Bukan [musuh palsu], tapi [musuh asli]"
[8-25s]  FRAMEWORK    3-5 langkah / poin
[25-40s] EXAMPLE      Kasus konkret
[40-55s] PAYOFF       Insight utama
[55-60s] CTA          "Save", "Follow untuk bagian 2"
```

### PATTERN D — VIRAL STORYTELLING (30–60 detik)

```
[0-3s]   HOOK              Cliffhanger / Confession
[3-10s]  SCENE             Setup spesifik (waktu, tempat, orang)
[10-20s] TENSION           Konflik / kegagalan / kerugian
[20-30s] TURNING POINT     "Sampai akhirnya..." / "Ternyata..."
[30-45s] MECHANISM         Alasan sebenarnya / pelajaran
[45-55s] PROOF             Hasil sekarang
[55-60s] LESSON / CTA      Insight + ajakan halus
```

## 4. 7 Hidden Drives (Psikologi Inti)

Setiap konten viral menyentuh minimal 1:

1. **Takut salah** → "Selama ini gue keliru?"
2. **Ingin cepat paham** → "Oh, sesederhana itu?"
3. **Butuh validasi** → "Bukan cuma gue."
4. **Ingin naik status** → "Gue lebih pintar."
5. **Takut tertinggal** → "Semua udah tahu?"
6. **Butuh kambing hitam** → "Bukan salah gue."
7. **Butuh harapan** → "Kalau dia bisa, gue juga."

Hook terbaik = combine 2–3 trigger psikologi sekaligus.

## 6. AIDA for TikTok — Bikin Hook Sendiri

`A.I.D.A` versi short-form:
- **A — Audience**: hook untuk ibu rumah tangga ≠ anak Jaksel. Sesuaikan bahasa.
- **I — Insight**: cari pain point berulang di komentar kompetitor / Reddit Indonesia / X.
- **D — Drama**: tambah kontradiksi, magnitude, atau personal stake.
- **A — Action verb**: mulai dengan "Stop", "Lihat", "Ternyata", "Nyesel". Hindari "Halo guys", "Di video ini..."

---

## 7. 5 Kesalahan Hook yang Bikin Video Tenggelam

1. **Hook >7 detik** — penonton skip sebelum inti.
2. **Hook tidak match isi** — clickbait → completion rate turun → algoritma de-prioritize.
3. **Visual lemah saat hook** — narasi bagus, background sepi → skip.
4. **Audio tidak match** — sound trending tanpa konteks bikin algoritma bingung target audience.
5. **Eye contact lemah** — energi flat → skip.

---

## 8. Produksi Massal — Rumus 5 × 2 × 3 = 30

Standar industri performance creative 2026. Dari **1 winning concept**, hasilkan 30 iklan:
- **5 hooks** (variasi sudut dari Hook Bank)
- **2 proof types** (UGC testimonial vs demo, atau expert vs customer)
- **3 offers/CTA** (discount, bundle, garansi, free trial)

= 30 live ads dari 1 pemenang. "2 ads aja gagal lalu bilang TikTok mahal" = bukan test, itu coin flip.

Selaras dengan CAVAC MODE CEPAT: 1 template master → ganti hook + footage per variasi.

---

## 9. Checklist Final Sebelum Post/Launch

- [ ] Hook ≤3 detik, ≥1 trigger psikologi (idealnya 2–3)
- [ ] Bahasa = bahasa audience (curi dari komen kompetitor)
- [ ] Eye contact + energi tinggi di hook
- [ ] Visual reinforce narasi (bukan kontradiksi)
- [ ] Aspect ratio 9:16, safe zone dijaga
- [ ] Audio match niche (sound on/off keduanya jalan)
- [ ] Proof spesifik (angka/demo/before-after)
- [ ] CTA tunggal, jelas, ringan
- [ ] Hook tidak berbohong terhadap isi
- [ ] Variant siap untuk batch testing (min. 5 hook × 2 proof × 3 offer)

## 10. Metrik Diagnosa

| Metrik | Target Sehat | Diagnosa Jika Gagal |
|--------|--------------|---------------------|
| 3s view rate | >65% | Hook lemah |
| Hold rate (6s) | >40% | Body lambat |
| Completion rate | >25% (15s ad), >15% (30s) | Pacing jelek / janji tidak deliver |
| CTR | >1.5% TikTok, >2% Meta | CTA tidak jelas / offer lemah |
| CPM | Stabil/turun saat scale | Audience terlalu sempit |
| ATC ratio | >15% | Belum cukup kuat untuk push |
| CPA / CPL | Tergantung industri | Mismatch hook ↔ offer ↔ landing |

Pola diagnosa dari case Krom/skincare (selaras CAVAC case study):
- **ATC tinggi + Initiated Checkout anjlok** = value tidak cukup memotivasi → BUKAN harga, BUKAN landing
- Solusi: ganti **POV + value** (Audience POV → Product POV), bukan cuma ganti landing page

## 11. Workflow Penggunaan (Saat User Datang)

### Step 0 — Cek apakah produk sudah disebut
- **Belum** → bangun framework dulu pakai 12 Hook Bank + 4 Skeleton + 7 Drives. Tunggu detail produk untuk implementasi v2.
- **Sudah** → lanjut ke step berikut.

### Step 1 — Tanya 7 hal minimum sebelum generate
1. Produk apa
2. Kategori / niche
3. Concrete value (bahan, fitur, build, packaging, hasil terukur)
4. CEP utama (kapan orang butuh) — pakai CAVAC SKILL.md
5. Harga + offer struktur
6. Bukti yang sudah ada (testi, review, before-after, demo)
7. Channel utama (TikTok organik / TikTok Ads / IG Reels / FB Ads / semua)

### Step 2 — Output yang dijanjikan
- 30–50 hook variants berbasis 12 pattern (pakai Pattern 1, 2, 7, 8, 11 lebih banyak untuk entry)
- 4 script skeleton siap shoot (Performance / UGC / Organic / Storytelling)
- Hook-Body-CTA matrix untuk batch test 5×2×3 = 30 ads
- Editorial calendar 14 hari untuk organic content

### Step 3 — Guard Rails
- Pastikan semua hook + script = Product POV jika brand baru entry (selaras CAVAC).
- Hook tidak boleh berbohong → cek apakah body deliver janji hook.
- Jangan biarkan user lompat ke Aspirational Value sebelum Concrete terbukti.
- Variasi hook harus dari ≥4 kategori berbeda (jangan 30 hook semua "Mistake").
