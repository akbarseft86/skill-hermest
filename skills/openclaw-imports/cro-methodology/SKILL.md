# CRO Methodology

Scientific, customer-centric approach to conversion rate optimization. Rejects "best practices" in favor of evidence-based testing—understand WHY visitors don't convert before changing anything.

Based on Karl Blanks & Ben Jesson's "Making Websites Win" (Conversion Rate Experts methodology used by Google, Apple, Amazon, Dropbox).

## Core Philosophy

1. **Don't copy competitors** — They probably haven't tested either
2. **Understand before changing** — Research WHY visitors don't convert
3. **Bold hypotheses** — Don't test button colors; test fundamental value propositions
4. **Evidence over opinion** — Every change should be backed by customer evidence

## When to Use

- Audit a landing page or website for conversion issues
- Identify why visitors aren't converting (objections vs. UX problems)
- Write persuasive copy that addresses customer objections
- Design A/B tests with bold hypotheses
- Find hidden "persuasion assets" you're not using
- Map and optimize a conversion funnel
- Create an objection/counter-objection framework

## CRO Audit Framework

### Step 1: Identify the Conversion Goal
- What specific action should visitors take?
- What's the current conversion rate?
- What's the benchmark or target?

### Step 2: Map the Visitor Journey
- Where do visitors come from? (traffic source context)
- What do they see first? (above-the-fold analysis)
- What's the path to conversion?
- Where do they drop off?

### Step 3: Discover Objections (The O/CO Framework)

Create an Objection / Counter-Objection table:

| # | Objection (Why they DON'T convert) | Counter-Objection (Evidence to overcome it) | Where to Place |
|---|---|---|---|
| 1 | "Is this worth my money?" | ROI calculator, case studies with numbers | Above fold, pricing page |
| 2 | "Can I trust this company?" | Testimonials, credentials, media logos | Below hero, sidebar |
| 3 | "Will this work for MY situation?" | Specific use cases, segmented testimonials | Feature sections |
| 4 | "What if it doesn't work?" | Guarantee, free trial, easy cancellation | Near CTA |
| 5 | "Is now the right time?" | Urgency (real), cost of waiting, quick wins | CTA area |

### Step 4: Find Persuasion Assets

Audit for missing persuasion elements:

**Social Proof**:
- [ ] Customer testimonials (specific, with numbers)
- [ ] Case studies with before/after results
- [ ] Number of customers/users
- [ ] Media mentions / "As seen in"
- [ ] Expert endorsements
- [ ] User-generated content

**Credibility**:
- [ ] Awards and certifications
- [ ] Years in business
- [ ] Team credentials
- [ ] Security badges
- [ ] Money-back guarantee

**Clarity**:
- [ ] Clear headline stating value proposition
- [ ] Subheadline expanding on benefits
- [ ] Visual hierarchy guiding eye flow
- [ ] Single, clear CTA per section
- [ ] Benefits over features

**Risk Reversal**:
- [ ] Free trial
- [ ] Money-back guarantee
- [ ] Easy cancellation
- [ ] No credit card required
- [ ] Sample/demo available

### Step 5: Prioritize & Test

**ICE Scoring for test priorities:**
- **Impact**: How much will this move the needle? (1-10)
- **Confidence**: How sure are we this will work? (1-10)
- **Ease**: How easy is this to implement? (1-10)

Score = (I + C + E) / 3

## Landing Page Copy Framework

### Above the Fold (5-second test)
1. **Headline**: What do you offer? (Specific benefit)
2. **Subheadline**: How does it help? (Supporting detail)
3. **Visual**: Show the outcome or product
4. **CTA**: Clear action button
5. **Social proof snippet**: Quick credibility

### Body Structure
1. **Problem agitation**: Describe the pain
2. **Solution introduction**: Your approach
3. **How it works**: 3 simple steps
4. **Proof**: Testimonials, case studies, data
5. **Objection handling**: Address top concerns
6. **Final CTA**: Clear, urgent, risk-free

## Key Principles

1. **The page should be a "slippery slide"** — Each element pulls reader to the next
2. **Remove friction before adding persuasion** — Fix confusing UX first
3. **Match message to traffic source** — Different ads need different landing pages
4. **Test one variable at a time** — Unless doing radical redesign tests
5. **Statistical significance matters** — Don't call winners too early

## Example Prompts

- "Audit this landing page and list the top 5 objections a visitor might have"
- "Create an O/CO table for our SaaS pricing page"
- "What persuasion assets are we missing on this page?"
- "Rewrite this headline to address the 'is this worth my time?' objection"
- "Design an A/B test hypothesis for our signup page"
