# Instagram Sales Account Analysis — Public-Data Fallback Pattern

Use when the user asks to analyze an Instagram sales/agent account but live Instagram access is blocked, rate-limited, or login-gated.

## Evidence hierarchy
1. Live Instagram profile/grid if accessible.
2. Search engine snippets for the profile and indexed reels/posts.
3. Public link-in-bio / website / landing page connected to the profile.
4. Public brand pages and official product/service pages for context.
5. Clearly labeled inference from patterns, never presented as verified account data.

## Fallback collection pattern
- Try the IG URL once; if blocked by login/429/CAPTCHA, do not keep hammering.
- Search exact handle in quotes and with `site:instagram.com/<handle>`.
- Search indexed reels/posts with product/offer keywords.
- Pull the linked website or landing page and map its CTA path.
- Capture cached metrics carefully: followers, following, posts, bio, area, CTA, examples of post captions, like/comment counts if snippets expose them.
- State the access limitation plainly: “IG live grid was blocked; analysis uses public search snippets + linked website.”

## Analysis sections for sales/agent IG accounts
1. Snapshot: handle, name, followers/posts if available, bio, area, CTA, linked funnel.
2. Positioning: what the account currently sells and the mental category it owns.
3. Funnel: IG → link/bio/site → WhatsApp/DM/landing; identify conversion bridge gaps.
4. Content pattern: repeated hooks, formats, offers, product/funnel emphasis, engagement signals.
5. Strengths: niche clarity, offer clarity, trust assets, proof, website/WA readiness.
6. Weaknesses: too product-led, pricing too early, weak hooks, brochure-like reels, missing objection handling, missing personal authority.
7. Opportunity angles: problem-aware hooks, calculator/simulator angle, service proof, objection handling, lifestyle/status angle, personal advisor angle.
8. Repositioning: shift from seller/catalog to advisor/audit/helper when appropriate.
9. Content pillars: problem awareness, cost calculator, objection handling, service proof, demos, personal authority.
10. Quick-win plan: 7–14 day content/funnel actions with CTA scripts.
11. WhatsApp pre-screening: questions that turn inbound leads into consultative diagnosis.
12. Sharp conclusion: what is already working, biggest bottleneck, and the most realistic next move.

## Quality rules
- Do not overclaim real-time metrics from snippets; say “around/cached/public snippet shows”.
- Separate fact vs interpretation.
- For repeated low-engagement snippets, say “signal/indikasi”, not definitive performance diagnosis.
- Make recommendations operational: hook examples, CTAs, WhatsApp questions, content pillars, and next-14-day plan.
