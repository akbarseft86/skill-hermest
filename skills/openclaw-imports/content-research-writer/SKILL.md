# Content Research Writer

This skill acts as your writing partner, helping you research, outline, draft, and refine content while maintaining your unique voice and style.

## When to Use This Skill

- Writing blog posts, articles, or newsletters
- Creating educational content or tutorials
- Drafting thought leadership pieces
- Researching and writing case studies
- Producing technical documentation with sources
- Writing with proper citations and references
- Improving hooks and introductions
- Getting section-by-section feedback while writing

## What This Skill Does

1. **Collaborative Outlining**: Helps structure ideas into coherent outlines
2. **Research Assistance**: Finds relevant information and adds citations
3. **Hook Improvement**: Strengthens opening to capture attention
4. **Section Feedback**: Reviews each section as you write
5. **Voice Preservation**: Maintains writing style and tone
6. **Citation Management**: Adds and formats references properly
7. **Iterative Refinement**: Helps improve through multiple drafts

## Instructions

When a user requests writing assistance:

### 1. Understand the Writing Project

Ask clarifying questions:
- What's the topic and main argument?
- Who's the target audience?
- What's the desired length/format?
- What's your goal? (educate, persuade, entertain, explain)
- Any existing research or sources to include?
- What's your writing style? (formal, conversational, technical)

### 2. Collaborative Outlining

Help structure the content:

```markdown
# Article Outline: [Title]

## Hook
- [Opening line/story/statistic]
- [Why reader should care]

## Introduction
- Context and background
- Problem statement
- What this article covers

## Main Sections

### Section 1: [Title]
- Key point A
- Key point B
- Example/evidence
- [Research needed: specific topic]

### Section 2: [Title]
- Key point C
- Key point D
- Data/citation needed

### Section 3: [Title]
- Key point E
- Counter-arguments
- Resolution

## Conclusion
- Summary of main points
- Call to action
- Final thought

## Research To-Do
- [ ] Find data on [topic]
- [ ] Get examples of [concept]
- [ ] Source citation for [claim]
```

### 3. Conduct Research

When user requests research on a topic:
- Search for relevant information
- Find credible sources
- Extract key facts, quotes, and data
- Add citations in requested format

### 4. Improve Hooks

When user shares an introduction, analyze and strengthen:

**Current Hook Analysis**:
- What works: [positive elements]
- What could be stronger: [areas for improvement]
- Emotional impact: [current vs. potential]

**Suggested Alternatives** (provide 3 options):
- Option 1: Bold statement
- Option 2: Personal story
- Option 3: Surprising data

**Hook Checklist**:
- Does it create curiosity?
- Does it promise value?
- Is it specific enough?
- Does it match the audience?

### 5. Section-by-Section Feedback

As user writes each section, review for:

- **Clarity**: Specific issues → Suggested fixes
- **Flow**: Transition issues → Better connections
- **Evidence**: Claims needing support → Add citation or example
- **Style**: Tone inconsistency → Match voice better
- **Specific Line Edits**: Original → Suggested → Why

### 6. Preserve Writer's Voice

Important principles:
- **Learn their style**: Read existing writing samples
- **Suggest, don't replace**: Offer options, not directives
- **Match tone**: Formal, casual, technical, friendly
- **Respect choices**: If they prefer their version, support it
- **Enhance, don't override**: Make their writing better, not different

### 7. Final Review and Polish

When draft is complete, provide comprehensive feedback on:
- Overall Assessment (strengths, impact)
- Structure & Flow
- Content Quality
- Technical Quality
- Readability
- Final Polish Suggestions
- Pre-Publish Checklist

## Writing Workflows

### Blog Post: Outline → Research → Intro feedback → Body feedback → Conclusion → Polish
### Newsletter: Hook ideas → Quick outline → Draft → Clarity review → Polish
### Technical Tutorial: Outline steps → Code examples → Explanations → Test → Troubleshooting → Review
### Thought Leadership: Unique angle → Research perspectives → Thesis → Strong POV → Evidence → Conclusion

### Competitive Intelligence / Performance Marketing Research
- For Instagram competitor accounts blocked by login/rate limits, use `references/instagram-competitor-snippet-research.md` to turn public cached snippets into cautious but actionable positioning/funnel analysis.
Use when the user asks for competitor research that must inform ads, TikTok, WhatsApp, landing pages, funnels, pricing, or positioning.

Workflow:
1. Cover both product competitors and channel/sales competitors competing for the same leads.
2. Separate direct competitors, indirect substitutes, and same-brand agents/affiliates/resellers.
3. Use only public sources; do not impersonate buyers or enter private groups.
4. Check Meta Ad Library and short-video/TikTok patterns when requested; if access is blocked, state limitation and mark inferred insights clearly.
5. Report in decision-ready tables: competitor, offer, price/skema, service, funnel, hook, CTA, complaints, source.
6. Distinguish facts, estimates, and interpretation.
7. Use “indikasi winning” for duration/repetition/creative-volume evidence; avoid claiming “terbukti winning” without actual performance data.
8. End with actionable strategy: positioning gaps, ad angles, WhatsApp hooks, pre-screening questions, low-budget funnel, and a short execution plan.

See `references/competitive-intelligence-performance-research.md` for a reusable table schema, ethical guardrails, price perception ladder, and Coway-style subscription-product synthesis pattern.

### Instagram Sales / Agent Account Analysis
Use when the user asks to analyze an Instagram account that sells a product/service, especially agent/affiliate/Health Planner style accounts with a website, link-in-bio, WhatsApp CTA, or local service area.

Workflow:
1. Collect public evidence from the IG profile if accessible; if blocked, use search snippets plus linked website/landing page and clearly state the limitation.
2. Map snapshot, positioning, funnel, content pattern, strengths, weaknesses, conversion gaps, and practical next actions.
3. Do not stop at descriptive audit. Translate every finding into hooks, content pillars, CTAs, WhatsApp pre-screening, and a 7–14 day execution plan.
4. For sales accounts, check whether the account is seller/catalog-led or advisor/problem-led; recommend a consultative repositioning when suitable.
5. Use cached metrics carefully: say “public snippet shows” or “around”, and separate facts from interpretation.

See `references/instagram-sales-account-analysis.md` for the fallback evidence hierarchy and reusable section structure.
